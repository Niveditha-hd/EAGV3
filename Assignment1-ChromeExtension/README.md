# Chrome Extension - Daivik's Current Affairs Club

This extension pos up Kid-friendly current affairs from RobinAge (RSS), with GKToday called out for extra GK, plus vocabulary, geography, rivers, and a mini-quiz.

## 🚀 Features
* **Current Affairs:** Three current affairs news in "Did you know" format from RobinAge kids newspaper.
* **Sports:** One sports news.
* **Science:** One science news.
* **Vocabulary:** One new word.
* **Quiz:** Quiz on the news with 6 questions.

## 🛠 Installation

### For Users (Web Store)
1. Visit the [Chrome Web Store](https://chromewebstore.google.com/) page.
2. Click **Add to Chrome**.

### For Developers (Manual/Local Loading)
To run this extension locally during development:
1. Clone this repository: `git clone https://github.com`
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** using the toggle in the top right.
4. Click **Load unpacked** and select the root directory of this project.

* **Popup:** Click the extension icon in the toolbar to [action].
